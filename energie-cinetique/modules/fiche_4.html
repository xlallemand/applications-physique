Théorème de l'énergie cinétique

Le théorème (à connaître)

ΔEc = Ec(B) − Ec(A) = WAB(F1) + WAB(F2) + …

½ m vB2 − ½ m vA2 = Σ WAB

Σ W > 0 : la vitesse augmente ; Σ W < 0 : elle diminue ; Σ W = 0 : elle ne change pas.

Exemple

Ec(A) = 40 J ; une force motrice fournit 60 J, les frottements retirent 20 J : Ec(B) = 40 + 60 − 20 = 80 J.

Utilisation : chute

Méthode :

  1. schéma : A, B, déplacement, chaque force et son angle α, données (vA, vB, h ou AB, m) ;
  2. théorème ;
  3. chaque travail : force ⊥ au déplacement → 0 ; α = 180° → cos α = −1 ;
  4. application numérique (vitesses en m/s) ;
  5. isoler l'inconnue.

Chute : W(P) = m g h ; si vA = 0, vB = √(2 g h).

Exemple

Pomme lâchée de 10 m (g = 10) : vB = √200 ≈ 14,1 m/s.

Utilisation : lancé vers le haut

Lancer vers le haut : W(P) = −m g h ; au sommet, vB = 0 : h = vA2 / (2 g).

Exemple

Pomme lancée à 10 m/s (g = 10) : h = 10² / 20 = 5 m.

Utilisation : freinage (route horizontale)

W(P) = W(RN) = 0 (⊥ au déplacement) ; W(f) = −f × AB.

Freinage jusqu'à l'arrêt : −½ m vA2 = −f × AB, donc f = ½ m vA2 / AB.

Exemple

900 kg, 50 km/h, arrêt sur 10 m : f ≈ 8,7 × 103 N.

Utilisation : distance d'arrêt

Même théorème que pour le freinage : AB = ½ m vA2 / f.

Exemple

800 kg, 70 km/h, f = 9,0 × 103 N : AB ≈ 16,8 m.

Utilisation : démarrage

W(Fm) = Fm × AB (α = 0°) ; W(f) = −f × AB.

Démarrage (vA = 0) : ½ m vB2 = Fm × AB − f × AB.

Exemple

800 kg, 0 → 20 km/h sur 12 m, Fm = 1,3 × 103 N : f ≈ 271 N.
