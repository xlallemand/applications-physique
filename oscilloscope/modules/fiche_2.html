Mesurer une fréquence

Mesurer T en comptant les carreaux

On compte les carreaux de n périodes (le plus grand nombre possible, entre deux sommets), puis :

T = nombre de carreaux × base de tempsn

On utilise la base de temps (Time), jamais la sensibilité verticale (CH1). Changer la base de temps change l'affichage, pas la période.

Exemple

2 périodes occupent 8 carreaux ; Time : 500 µs par carreau.

T = 8 × 5002 = 2 000 µs = 2,00 ms

Mesurer T avec les curseurs

  1. Appuyer sur Cursor : le menu des curseurs s'affiche à droite de l'écran.
  2. Avec le 1er bouton à droite de l'écran, régler Mode : Manuel.
  3. Avec le 2e bouton, choisir Type : X (curseurs horizontaux, pour mesurer une durée).
  4. Choisir CurA (4e bouton) et tourner le bouton de réglage pour placer le curseur A sur un sommet.
  5. Choisir CurB (5e bouton) et placer le curseur B n périodes plus loin. CurA et CurB choisis ensemble bougent en même temps.
  6. Lire ΔX, la durée entre les deux curseurs.

T = ΔXn

Exemple : son d'un diapason (la3)

Entre les curseurs A et B, 2 périodes : T = 4 540 / 2 = 2 270 µs = 2,27 ms.

La fréquence

f = 1T    f en hertz (Hz), T en secondes (s)

1 ms = 10−3 s ; 1 µs = 10−6 s. Exemple : T = 2,27 ms = 2,27 × 10−3 s, donc f = 1 / (2,27 × 10−3) ≈ 441 Hz.
