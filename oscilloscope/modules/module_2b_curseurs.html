Fréquence : utiliser les curseurs

L'oscilloscope peut mesurer lui-même la durée entre deux curseurs que l'on place sur l'écran : c'est ΔX, affiché sous l'écran. Les réglages se font comme sur l'appareil du lycée : touche Cursor, boutons du menu à droite de l'écran, bouton de réglage.
