Mesurer une tension

Mesurer Umax en comptant les carreaux

Pour un signal centré sur 0 V, on compte les carreaux entre le 0 V de sa voie (repère 1 ▸ ou 2 ▸) et le maximum, puis :

Umax = nombre de carreaux × sensibilité verticale

Chaque voie a sa propre sensibilité : on lit celle de la voie du signal mesuré (CH1 pour le signal jaune, CH2 pour le signal bleu). La base de temps (Time) ne sert pas pour une tension.

Exemple

Signal jaune : 3 carreaux du 0 V au maximum, CH1 : 2,00 V par carreau : Umax = 3 × 2,00 = 6,0 V.

Signal bleu : 2,4 carreaux, CH2 : 500 mV = 0,5 V par carreau : Umax = 2,4 × 0,5 = 1,2 V.

Mesurer Umax avec les curseurs

  1. Appuyer sur Cursor : le menu des curseurs s'affiche à droite de l'écran.
  2. Avec le 1er bouton à droite de l'écran, régler Mode : Manuel.
  3. Avec le 2e bouton, choisir Type : Y (curseurs verticaux, pour mesurer une tension).
  4. Avec le 3e bouton, Source, choisir la voie du signal mesuré (CH1 ou CH2) : les valeurs des curseurs sont calculées avec son échelle, depuis son 0 V.
  5. Placer un curseur au maximum et l'autre au minimum du signal, puis lire ΔY.

Umax = ΔY2

Si le signal est centré sur 0 V, la valeur du curseur placé au maximum est aussi Umax. S'il n'est pas centré, elle ne l'est plus : Umax = ΔY / 2 convient toujours.

Exemple : signal centré sur 0 V

CurA au maximum : Umax = 4,60 V. Avec ΔY : Umax = 9,20 / 2 = 4,60 V.

Exemple : le même signal, décalé (non centré)

CurA au maximum vaut 7,00 V : ce n'est pas Umax. Avec ΔY : Umax = 9,20 / 2 = 4,60 V.
