MODULE 3 · FICHE RÉCAPITULATIVE

Accélération

Définition (à connaître)

a = dvdt = v′

Variation de la vitesse au cours du temps, en m·s−2.

Quatre façons de calculer a, selon ce que l'on connaît : l'expression de v(t) : a = v′ ; une vitesse constante : a = 0 ; une vitesse de départ et d'arrivée (a considérée constante) : a = Δv / Δt ; les forces : a = Σ F / m.

Dériver la vitesse

a = v′

Pour v = k × t + v0, a = k : la dérivée d'une constante est nulle.

Exemple

v = 7,25 t donne a = 7,25 m·s−2.

Vitesse constante

a = 0

La vitesse ne varie pas.

Accélération constante

a = ΔvΔt = vfin − vdébutdurée

Négative : le système ralentit ; pour la valeur, on garde le nombre positif.

km/h → m/s : on divise par 3,6 (100 km/h ≈ 27,8 m/s).

Exemple

De 0 à 100 km/h en 2,5 s : a = 27,8 / 2,5 ≈ 11,1 m·s−2.

Accélération et forces

a = Σ Fm

Σ F en N, m en kg, a en m·s−2 (principe fondamental de la dynamique, module 4).
