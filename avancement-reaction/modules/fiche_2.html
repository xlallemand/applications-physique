Le tableau d'avancement

L'avancement x

L'avancement x est le nombre de fois que la réaction a eu lieu (x = 0 au départ). La réaction s'arrête pour l'avancement maximal xmax.

La méthode du tableau

1. État initial : les quantités de départ ; 0 pour les produits.

2. État en cours : réactif : ninitial − nombre stœchiométrique × x ; produit : ninitial + nombre stœchiométrique × x.

3. Hypothèses : pour chaque réactif, on suppose qu'il est épuisé (quantité finale nulle) et on calcule xmax.

4. Conclusion : on garde la plus petite valeur de xmax ; ce réactif est le réactif limitant.

5. État final : on remplace x par xmax dans la ligne « en cours ».

Exemple : 3 CH4 et 4 O2

CH4 + 2 O2 → CO2 + 2 H2O
