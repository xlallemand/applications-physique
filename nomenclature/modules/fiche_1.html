Représenter les molécules

Combien de liaisons ?

Règle du duet pour H (un doublet, liant : 1 liaison) ; règle de l'octet pour les autres (4 doublets).

Doublets non liants = 4 − doublets liants : on complète par des doublets non liants pour avoir 4 doublets, soit 8 électrons (règle de l'octet).

Dans la classification : nombre de liaisons = nombre de cases à parcourir vers la droite jusqu'à la colonne des gaz nobles.

Les H complètent les liaisons de chaque atome. Un atome avec trop (ou pas assez) de liaisons : formule impossible.

Les trois écritures

Développée (formule de Lewis) : tous les atomes, toutes les liaisons, les doublets non liants.

Semi-développée : les H regroupés sur leur atome (CH₃, CH₂, CH, OH, NH₂). La plus utilisée cette année. Écritures abrégées : C₂H₅ = –CH₂–CH₃ ; (CH₂)₅ = cinq –CH₂– à la suite ; C₆H₅ = cycle benzénique qui porte 5 H.

Topologique : ni les C, ni les H liés aux C ; zigzag ; chaque sommet et chaque bout de trait est un C ; les autres atomes écrits avec leurs H (OH, NH₂).

Passer d'une écriture à l'autre

Développée → semi-développée : « on enlève les liaisons des H et on les regroupe sur leur atome ».

Vers la topologique : « on efface tous les CH », puis le zigzag.

Depuis la topologique : « on ajoute un C avec le bon nombre de H au bout de chaque trait, s'il n'y a pas déjà un autre atome » (nombre de H = 4 − nombre de traits).
