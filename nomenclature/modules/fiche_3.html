Les familles

Familles et groupes caractéristiques (par cœur)

On trouve deux vocabulaires : famille et groupe caractéristique (le plus utilisé), ou classe fonctionnelle et groupe fonctionnel. On entoure le groupe, on écrit son nom, puis la famille entre parenthèses.

Amines : primaire, secondaire, tertiaire (1, 2 ou 3 C liés au N).

Le groupe carbonyle

C=O en bout de chaîne (le C porte un H) : aldéhyde ; C=O entre deux C : cétone.

Acides carboxyliques, esters, amides

Le C du C=O porte aussi un OH (acide carboxylique), un O lié à un C (ester) ou un N (amide).

Acide ≠ alcool + cétone ; ester ≠ acide ; amide ≠ amine + cétone ; aldéhyde ≠ cétone.

Nommer : alcènes, alcools, halogénoalcanes, aldéhydes, cétones, acides carboxyliques

La chaîne principale contient le groupe ; le n° est celui de l'atome de carbone qui porte le groupe caractéristique, le plus petit possible ; il s'écrit devant la terminaison.

-ène (but-2-ène), -ol (butan-2-ol), -al (butanal), -one (butan-2-one), acide …-oïque (acide butanoïque) ; halogènes en préfixe (2-chlorobutane), dans l'ordre alphabétique avec les ramifications. Devant une voyelle, « ane » perd son e.

Nommer : esters, amines, amides

Ester : alcanoate (chaîne du C=O, son C est le n° 1) d'alkyle (chaîne liée à l'O, numérotée à partir du C lié à l'O).

Amine : …an-n-amine, la chaîne la plus longue liée au N donne le nom. Amide : …anamide. Les ramifications sur le N : N- (N-éthyléthanamine : sur le N, il y a un éthyle accroché).
