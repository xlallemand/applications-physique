Antennes

Taille d'une antenne

Il faut une antenne pour émettre le signal et une antenne pour le recevoir. La taille d'une antenne est liée à la longueur d'onde : la taille optimale est λ ; en pratique on utilise un sous-multiple :

L = λn   :   demi-onde L = λ2   ;   quart d'onde L = λ4

Le sous-multiple le plus efficace est la demi-onde.

Méthode. Si on donne f : λ = c / f (f en Hz), puis L = λ / 2. Inversement : λ = 2 L, puis f = c / λ.

Exemple

f = 100 MHz : λ = 3,00 × 108 / (100 × 106) = 3,00 m ; antenne demi-onde L = 1,50 m.

Antenne bobinée

Le fil est enroulé autour d'une surface de périmètre p : nombre de tours = L / p (L et p dans la même unité).

Exemple (carte RFID à 135 kHz)

λ = 2 222 m ; L = λ / 2 = 1 111 m ; p = 2 × 6,5 + 2 × 4,5 = 22 cm = 0,22 m ; 1 111 / 0,22 ≈ 5 050 tours.
