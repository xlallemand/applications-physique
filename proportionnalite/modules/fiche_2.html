Utiliser la proportionnalité

Méthode 1 : le tableau de proportionnalité

Les deux grandeurs dans un tableau, avec les unités (convertir d'abord si besoin). Produit en croix :

? = (c × b) / a

Proportionnalité inverse : le produit d'une ligne est constant :

? = (a × b) / c

Gaz : 2 L sous 6 bar ; sous 4 bar, V = (6 × 2) / 4 = 3 L.

Méthode 2 : le coefficient de proportionnalité

k = b / a   puis   ? = k × c

Proportionnalité inverse : k = a × b, puis ? = k / c.

Batterie : 60 Wh pour 0,4 kg, donc k = 60 / 0,4 = 150 Wh/kg ; pour 1,4 kg : E = 150 × 1,4 = 210 Wh.

Méthode 3 : le retour à l'unité

1 unité de A → b / a   puis   ? = (b / a) × c

25 points sur 36 : 25 / 36 ≈ 0,694 par point, donc 0,694 × 20 ≈ 13,9 / 20.

Les trois méthodes donnent toujours le même résultat.
