Décroissance exponentielle et calcul de t

La loi de décroissance

N(t) = N0 e−λt

N0 : nombre initial de noyaux ; λ : constante radioactive (probabilité de désintégration d'un noyau par unité de temps). Calcul de N : touche ex.

A(t) = A0 e−λt   avec   A0 = λ N0

Car A = −dN/dt et (eax)′ = a eax : A = λ N0 e−λt = λN.

Isoler t avec ln

ln, le logarithme népérien, est la fonction réciproque de ex : ln(ea) = a (comme log et 10x pour le pH).

N0 e−λt = N ⇔ e−λt = N/N0 ⇔ −λt = ln(N/N0) ⇔ t = ln(N/N0) / (−λ)

Calculer t

t = ln(N / N0)−λ   ou   t = ln(A / A0)−λ

Touche ln (pas log) ; t est positif ; t a l'unité de temps de λ.

Exemple

N0 = 1,0 × 106, N = 2,5 × 105, λ = 0,020 s−1 : t = ln(0,25) / (−0,020) ≈ 69,3 s.
