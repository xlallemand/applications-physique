MODULE 1 · MÉTHODE

Méthode pour utiliser une équation

Tu vas apprendre les règles qui permettent d'isoler une grandeur dans une équation : faire passer un terme de l'autre côté du signe =, utiliser le 1, écrire l'équation dans l'autre sens. Chaque règle se manipule ensuite dans l'éditeur d'équation, par glisser-déposer.
