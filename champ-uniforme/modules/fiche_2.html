Chute libre dans un champ de pesanteur uniforme

Chute libre, chute sans vitesse initiale

Chute libre : seul le poids P = m g agit. Dans le référentiel terrestre supposé galiléen, d'après la deuxième loi de Newton, m a = m g, donc a = g : vertical, vers le bas, g = 9,81 m·s−2 (= 9,81 N·kg−1), indépendant de la masse.

Sans vitesse initiale (axe z vers le haut, origine au sol) : vz(t) = −g t ; z(t) = −½ g t2 + h ; sol atteint pour z = 0 :

tchute = √(2h / g)

h = 2,0 m : tchute = 0,64 s.

Vitesse initiale horizontale

vx = v0 ; vy = −g t ; x = v0 t ; y = −½ g t2 + h. Mouvement plan (z = 0, dans le plan de g et v0).

y = −g x2 / (2 v02) + h   (parabole)

d = v0 tchute ; v0 = 5,0 m·s−1, h = 2,0 m : d = 3,2 m. Courbes : x(t) droite, y(t) parabole, vx constante, vy droite de pente −g.

Vitesse initiale quelconque

v0x = v0 cos α ; v0y = v0 sin α.

vx(t) = v0 cos α ; vy(t) = −g t + v0 sin α ; x(t) = (v0 cos α) t ; y(t) = −½ g t2 + (v0 sin α) t + h.

y = −g x2 / (2 (v0 cos α)2) + (tan α) x + h
