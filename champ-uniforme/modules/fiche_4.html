Accélérateurs de particules

Accélération dans un condensateur

Particule de charge q > 0 partant de O sans vitesse initiale, condensateur de largeur L, poids négligé : m a = q E.

ax = qE / m ; vx(t) = (qE / m) t ; x(t) = (qE / 2m) t2 ; x(tsortie) = L donne tsortie = √(2mL / (qE)).

vsortie = √(2qU / m)

Dépend de U, de q et de m, pas de L. Proton, U = 10 kV : v = 1,4 × 106 m·s−1. Tension nécessaire : U = m v2 / (2q). Un électron part de l'armature −.

Accélérateur linéaire et applications

Succession de condensateurs ; chaque fois que la particule change de condensateur, la polarité est inversée pour que le champ soit toujours dans le bon sens. Après n étages :

vn = √(2nqU / m)

On accélère fortement avec des tensions relativement faibles.

Applications : canon à électrons (tube cathodique de télévision, oscilloscope), accélérateurs linéaires du CERN (avant les anneaux), radiothérapie, analyse d'œuvres d'art ; aussi Van de Graaff, cyclotron, imprimante à jet d'encre, expérience de Millikan.
