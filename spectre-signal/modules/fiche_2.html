Le spectre

Lire un spectre

Le spectre représente l'amplitude des sinusoïdes qui composent le signal en fonction de leur fréquence.

  • raie à 0 Hz : la composante continue a0 (valeur moyenne) ;
  • première raie après 0 Hz : le fondamental, de fréquence f1 = fréquence du signal ;
  • raies suivantes : les harmoniques de rang n, de fréquences fn = n × f1 et d'amplitudes an.

Exemple du cours

a0 = 1 000 mV ; f1 = 150 Hz, a1 = 1 500 mV ; 300 Hz : a2 = 1 000 mV ; 450 Hz : a3 = 670 mV ; 600 Hz : a4 ≈ 170 mV.

Rang d'un harmonique

fn = n × f1   ;   n = fn / f1

Le rang est un nombre entier. Ce n'est pas la position de la raie sur le dessin : des harmoniques peuvent manquer (amplitude nulle).

Une raie dont la fréquence n'est pas un multiple de f1 est impossible.

Exemple

f1 = 50 Hz : rang 3 à 150 Hz ; rang 7 à 350 Hz ; une raie à 175 Hz est impossible (175 / 50 = 3,5). f1 = 200 Hz : la raie à 1 800 Hz est de rang 1 800 / 200 = 9.
