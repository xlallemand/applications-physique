Oxydants et réducteurs

Oxydant et réducteur

Un oxydant est une espèce chimique qui capte des électrons : Cu2+ capte 2 électrons pour devenir Cu.

Un réducteur est une espèce chimique qui cède des électrons : Fe2+ cède 1 électron pour devenir Fe3+.

Couple et demi-équation

Un couple est noté Oxydant / Réducteur. Sa demi-équation :

Oxydant + n e− = Réducteur

Une oxydation forme l'oxydant (demi-équation lue à l'envers) : Réducteur → Oxydant + n e−

Une réduction forme le réducteur (demi-équation lue à l'endroit) : Oxydant + n e− → Réducteur

Écrire une réaction d'oxydoréduction

  1. repérer les réactifs dans les deux demi-équations données ;
  2. orienter chaque demi-équation : le réactif à gauche ;
  3. multiplier les demi-équations pour avoir le même nombre d'électrons ;
  4. additionner membre à membre : les électrons s'éliminent.

Exemple

Réaction entre Fe3+ et Zn :
2 × (Fe3+ + e− → Fe2+)  (réduction)
1 × (Zn → Zn2+ + 2 e−)  (oxydation)

2 Fe3+ + Zn → 2 Fe2+ + Zn2+
