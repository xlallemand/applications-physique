Le Cours : Oxydoréduction

Oxydants et Réducteurs

Un OXYDANT

C'est une espèce chimique qui CAPTE des électrons.

Exemples :
• Cu2+ peut capter 2 électrons pour devenir Cu
• Fe3+ peut capter 1 électron pour devenir Fe2+

Un RÉDUCTEUR

C'est une espèce chimique qui CÈDE des électrons.

Exemples :
• Cu peut céder 2 électrons pour devenir Cu2+
• Fe2+ peut céder 1 électron pour devenir Fe3+

Oxydation et Réduction

Un couple est noté Oxydant / Réducteur. A ce couple correspond une demi-équation :

Demi-équation de référence Oxydant  +  n e−  =  Réducteur

Une OXYDATION…

…forme L'OXYDANT. On lit la demi-équation à l'envers :

Réducteur → Oxydant + n e−

Une RÉDUCTION…

…forme LE RÉDUCTEUR. On lit la demi-équation à l'endroit :

Oxydant + n e− → Réducteur

Comment écrire une réaction d'oxydoréduction

Les deux demi-équations des couples sont toujours données.

Méthode
Exemple : Fe3+ + Zn
1Identifier les réactifs et les repérer dans les demi-équations.

Demi-équations données :

• Fe3+ + e− = Fe2+

• Zn2+ + 2 e− = Zn

2Orienter les équations. Une des deux demi-équations doit être inversée pour que le réactif entouré soit à gauche. La flèche part du réactif vers le produit.

Fe3+ + e− → Fe2+  (réduction)

Zn → Zn2+ + 2 e−  (oxydation)

3Égaliser les électrons — multiplier chaque équation par le bon coefficient.

2 × ( Fe3+ + e− → Fe2+ )

1 × ( Zn → Zn2+ + 2 e− )

4Additionner membre à membre. Les électrons s'éliminent.

2 Fe3+ + 2 e− → 2 Fe2+

Zn → Zn2+ + 2 e−

2 Fe3+ + Zn → 2 Fe2+ + Zn2+
