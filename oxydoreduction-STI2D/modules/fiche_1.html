Oxydants et réducteurs

Oxydant et réducteur

Un oxydant est une espèce chimique qui peut capter des électrons : Cu2+ capte 2 électrons pour devenir Cu.

Un réducteur est une espèce chimique qui peut céder des électrons : Fe2+ cède 1 électron pour devenir Fe3+.

Le nombre d'électrons se lit sur les charges : de Cu2+ (charge 2+) à Cu (charge 0), la charge diminue de 2 : 2 électrons captés.

Couple et demi-équation

Un couple est noté Oxydant / Réducteur. Sa demi-équation, avec les électrons du côté de l'oxydant :

Oxydant + n e− = Réducteur

Exemples : Cu2+ / Cu : Cu2+ + 2 e− = Cu ; Fe3+ / Fe2+ : Fe3+ + e− = Fe2+.

Oxydation et réduction

Une réduction forme le réducteur : l'oxydant capte des électrons (demi-équation lue dans le sens →).

Oxydant + n e− → Réducteur

Une oxydation forme l'oxydant : le réducteur cède des électrons (demi-équation lue dans le sens ←).

Réducteur → Oxydant + n e−

Pour reconnaître une transformation : électrons avant la flèche (captés), c'est une réduction ; après la flèche (cédés), c'est une oxydation.
