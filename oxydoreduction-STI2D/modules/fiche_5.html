Schéma de fonctionnement d'une pile

Anode et cathode

Réduction à la Cathode (consonne – consonne) ; Oxydation à l'Anode (voyelle – voyelle).

Cathode (+) : ox1 + e− = red1, des électrons y arrivent.

Anode (−) : red2 = ox2 + e−, des électrons en partent.

ox1 + red2 → ox2 + red1

Dans les fils et dans le pont salin

Fils : des électrons, du − vers le + ; le courant I va du + vers le −.

Pont salin : des ions, il ferme le circuit. Anions dans le sens des e− (vers l'anode), cations dans le sens de I (vers la cathode) : à l'inverse de l'intuition.

Placer I et les électrons

Multimètre (valeur positive) : la borne COM est sur le −.

Chimie : l'électrode où l'espèce est oxydée (consommée) est le − ; les électrons en partent.

Exemple (exercice 8) : Zn = Zn2+ + 2 e− (anode, −) ; Cu2+ + 2 e− = Cu (cathode, +) ; Zn + Cu2+ → Zn2+ + Cu.
