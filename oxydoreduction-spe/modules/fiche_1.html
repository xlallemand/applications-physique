Oxydants, réducteurs et couples

Oxydant et réducteur

Un oxydant est une espèce capable de capter des électrons : Cu2+ capte 2 électrons pour devenir Cu.

Un réducteur est une espèce capable de céder des électrons : Fe2+ cède 1 électron pour devenir Fe3+.

Couple et demi-équation

Un couple se note Oxydant / Réducteur. Sa demi-équation, avec les électrons du côté de l'oxydant :

Oxydant + n e− = Réducteur

Exemples

Cu2+ + 2 e− = Cu  ·  Fe3+ + e− = Fe2+  ·  MnO4− + 8 H+ + 5 e− = Mn2+ + 4 H2O

Oxydation et réduction

Une oxydation est une perte d'électrons : Réducteur → Oxydant + n e−. Le réducteur est oxydé.

Une réduction est un gain d'électrons : Oxydant + n e− → Réducteur. L'oxydant est réduit.

Réaction d'oxydoréduction

C'est un transfert d'électrons entre l'oxydant d'un couple et le réducteur d'un autre couple :

Ox1 + Red2 → Red1 + Ox2

Exemple

Cu2+ + Zn → Cu + Zn2+ : Zn cède 2 électrons (il est oxydé), Cu2+ les capte (il est réduit).
