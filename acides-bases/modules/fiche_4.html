Quantités de matière

Calculer une quantité de matière

n = mM    n = c × V    n(H3O+) = [H3O+] × V    V = nc

m en g, M en g·mol−1, n en mol, c et [H3O+] en mol·L−1, V en L. Si on connaît le pH : [H3O+] = 10−pH.

Conversions : 1 m3 = 1 000 L ; 1 mL = 10−3 L.

Exemple : 60 m3 d'eau de pH 5,6 : [H3O+] ≈ 2,5 × 10−6 mol·L−1, n = 2,5 × 10−6 × 60 000 = 0,15 mol.

Relations stœchiométriques et schéma de la méthode

Pour a A + b B → c C + d D :

nA / a = nB / b = nC / c = nD / d

L'équation en tête, une colonne par espèce ; sous l'espèce connue : la donnée puis n ; la ligne des relations ; sous l'espèce cherchée : n puis la grandeur demandée (m = n × M, V = n / c).

Détartrage : n(CaCO3) = n(H3O+) / 2 = 5,0 × 10−3 mol ; m = 5,0 × 10−3 × 100 = 0,50 g de tartre éliminé.
