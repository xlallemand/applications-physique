Acides, bases et couples

Acide et base

Un acide AH est une espèce chimique capable de libérer un proton H+ :

AH → A− + H+

Une base A− est une espèce chimique capable de capter un proton H+ :

A− + H+ → AH

Couple acide / base et demi-équation

Un couple se note AH / A−, l'acide en premier. Sa demi-équation :

AH = A− + H+

L'acide est celui qui a le plus de H.

Couple acide / baseDemi-équation
H3O+ / H2OH3O+ = H2O + H+
CH3COOH / CH3COO−CH3COOH = CH3COO− + H+
H2O / HO−H2O = HO− + H+
NH4+ / NH3NH4+ = NH3 + H+

Espèce conjuguée et ampholyte

Base conjuguée d'un acide : on enlève un H+ (un H de moins, charge − 1). HNO3 → NO3− ; HPO42− → PO43−.

Acide conjugué d'une base : on ajoute un H+ (un H de plus, charge + 1). NH3 → NH4+ ; F− → HF.

Un ampholyte est l'acide d'un couple et la base d'un autre. L'eau est un ampholyte : acide du couple H2O / HO−, base du couple H3O+ / H2O.

Erreurs à éviter : oublier de changer la charge, écrire H+ du côté de l'acide, inverser l'acide et la base.
