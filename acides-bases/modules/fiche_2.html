Réactions acido-basiques

Réaction acido-basique

L'acide d'un couple donne un proton H+ à la base d'un autre couple. Chaque réactif devient son conjugué ; H+ n'apparaît pas dans l'équation.

Méthode directe : on déplace un H+ de l'acide vers la base.

H3O+ + CH3COO− → H2O + CH3COOH

H3O+ donne H+, qui vient se coller sur CH3COO−.

Règle du gamma γ

Les deux couples l'un sous l'autre (acide à gauche) ; on entoure les deux réactifs, en diagonale ; le γ relie chaque réactif à ce qu'il devient. Les produits sont les deux espèces non entourées.

NH3 + CH3COOH :

NH3 + CH3COOH → NH4+ + CH3COO−

NH4+ + H2O :

NH4+ + H2O → H3O+ + NH3

Deux acides ne réagissent pas ensemble, deux bases non plus. L'eau, ampholyte, réagit avec elle-même : 2 H2O → H3O+ + HO−.

Reconnaître les couples d'une réaction

On associe chaque réactif au produit qui a un H+ de plus ou de moins.

C9H8O4 + H2O → C9H7O4− + H3O+ : couples C9H8O4 / C9H7O4− et H3O+ / H2O.

NH4+ (acide) + PO43− (base) → NH3 (base) + HPO42− (acide).

H2CO3 = HCO3− + H+ n'est pas une réaction : c'est la demi-équation d'un seul couple.
