# Applications de Physique-Chimie (lycée)

Applications pédagogiques en HTML / CSS / JavaScript, ouvertes directement dans un navigateur (pas de serveur). Portail : `index.html` à la racine ; une application par dossier.

## Charte à respecter

**Avant de créer une nouvelle application, ou de modifier la présentation, la navigation ou la structure pédagogique d'une application existante, lis en entier [docs/charte-applications.md](docs/charte-applications.md).**

Elle décrit le style, la présentation des pages, la navigation (sommaire de toute l'application : toujours ouvert à gauche sur ordinateur, déroulé depuis un bandeau « où suis-je » sur téléphone ; accueil en lignes dépliables), la pédagogie (notion → exemple → « À toi », « Afficher tout le cours », séries notées sur 20, fiches, exercices) et la liste des vérifications avant livraison. L'application de référence est `cinematique/`.

## Règles permanentes

- Réponses et textes de l'interface en français, tutoiement, ton direct.
- Police sans empattement, couleurs uniquement via les variables de `assets/theme.css`.
- Code commenté en français.
- Fonctionnement à la souris et sur tout écran tactile.
- Ne modifier que ce qui est demandé.
