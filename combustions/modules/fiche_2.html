Équilibrer une combustion

Toujours la même équation

combustible + O2 → CO2 + H2O

Le dioxygène O2 est toujours un réactif ; le dioxyde de carbone CO2 et l'eau H2O sont toujours les produits.

Toujours le même ordre pour équilibrer

  1. C : le carbone, avec le nombre devant CO2 ;
  2. H : l'hydrogène, avec le nombre devant H2O ;
  3. O en dernier, avec le nombre devant O2 : cette molécule ne contient que de l'oxygène, la modifier ne change ni C ni H.

Uniquement des nombres entiers : s'il faudrait un demi de O2, on multiplie tous les nombres par 2.
